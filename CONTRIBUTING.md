# Contributing to Sparrow

1. Build with Xcode on macOS using the Sparrow project and iOS targets.
2. Keep changes native Swift/SwiftUI and preserve existing import/signing behavior.
3. Never commit certificates, provisioning profiles, private keys, passwords, tokens, or personal filesystem paths.
4. Include tests or a reproducible verification description with pull requests.
5. Preserve Feather attribution and GPL-3.0 requirements.
